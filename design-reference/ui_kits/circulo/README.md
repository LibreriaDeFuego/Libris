# Libris — UI Kit

Click-through recreation of the Libris mobile app (social reading-club product).

Screens: ficha del club, modal de actualizar progreso, feed de comentarios, feed de novedades, descubrir. Navigate via the bottom tab bar; tap "Actualizar progreso" or "Comentarios" from the club screen.

Built from `components/` primitives — Button, IconButton, Chip, BookCard, Blockquote, VoiceNotePlayer, SpoilerBlock, ProgressBar, Slider, Tabs, FilterPills, Modal, Icon.
