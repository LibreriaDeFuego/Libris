Pill-shaped action button in three weights: primary (coral fill, for the main action on a screen), secondary (cream card fill with border), ghost (text-only, for tertiary actions).

```jsx
<Button variant="primary" size="md">Actualizar progreso</Button>
<Button variant="secondary" size="sm">Compartir</Button>
<Button variant="ghost">Ver todos</Button>
```

Variants: `primary` | `secondary` | `ghost`. Sizes: `sm` | `md` | `lg`. Pass `icon` for a leading icon element. `disabled` dims to 45% opacity.
